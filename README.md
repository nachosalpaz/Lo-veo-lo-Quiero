🛍️ Lo veo Lo Quiero

¡Bienvenidos al repositorio de Lo veo Lo Quiero!

Este proyecto consiste en el desarrollo de una página web para un local de indumentaria, diseñada para mostrar prendas, destacar productos y ofrecer una experiencia de navegación atractiva, moderna e intuitiva.

📌 Descripción del proyecto

Lo veo Lo Quiero es una propuesta digital para un local de ropa que busca presentar sus productos de una manera visual y organizada, permitiendo a los usuarios conocer las prendas disponibles y descubrir las últimas tendencias.

El sitio está pensado para transmitir la identidad de la marca y facilitar el acceso a la información del local desde distintos dispositivos.

✨ Características

🛍️ Catálogo visual de prendas y productos.

🎨 Diseño moderno y atractivo.

📱 Interfaz adaptable a diferentes tamaños de pantalla.

🧭 Navegación sencilla e intuitiva.

👕 Secciones organizadas para mostrar los productos.

💻 Desarrollo con tecnologías web.

🛠️ Tecnologías utilizadas

HTML5: estructura y contenido de la página.

CSS3: estilos, diseño y adaptación visual.

JavaScript: interactividad y funcionalidades dinámicas.
